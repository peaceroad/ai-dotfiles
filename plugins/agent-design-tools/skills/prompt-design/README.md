# prompt-design

スキル、AGENTS.md、system/developer指示、プロンプトなど、モデルが従う指示文を設計・レビュー・改訂するスキルです。このREADMEは利用者向けの説明です。モデルへの指示と参照の読み込み条件は[SKILL.md](SKILL.md)にあります。

## 設計対象のモデル

依頼、会話で確定している前提、対象ファイルの導入先から、作成・改訂する指示を使うモデルを選びます。OpenAI/Codex向けで対象が決まっていなければ、**GPT-6 Astra向け**として扱います。

| 依頼や利用先の状況 | 設計対象 |
| --- | --- |
| 対象を指定せず、新しいスキルや指示を作る | Astra |
| 「GPT-5.6向け」と指定する | GPT-5.6 |
| 今回は指定がないが、既存の利用先がGPT-5.6と分かっている | GPT-5.6を引き継ぐ |
| 旧版はGPT-5.6向けだが、「Astra向けに更新して」と頼む | Astraへ切り替える |
| GeminiやGem向けと指定する、または会話で確定している | Gemini |

毎回モデル名を書く必要はありません。対象を示す情報を読んで判断するため、文章の書き方だけでモデルを確実に判別するものではありません。

**このスキルを実行しているモデルへの自動追従はしません。** たとえばGPT-5.6でこのスキルを使っても、OpenAI/Codex向けの設計対象が何も決まっていなければ、既定のAstra向けになります。参照を選ぶこと自体は、実行中モデルや導入先の設定を変更しません。

## 参照の使い分け

設計対象に応じて、Astra、GPT-5.6、Geminiの参照を選びます。移行や比較で必要な場合は、複数モデルの資料を使います。GPT-5.6向けでもモデルに依存しない文言修正なら、専用参照は省けます。

GemのInstructions・Knowledge、Geminiの画像・動画プロンプト、OpenAI APIのツール・状態管理などの詳細は、依頼に関係する参照を追加で読みます。

設計の判断、確認した動作、未検証の範囲は、[評価ノート](../../../../docs/prompt-design/README.md)と[モデル別参照のレビュー](../../../../docs/prompt-design/model-reference-review.md)に記録しています。
