API に渡すプロンプトは、次の形にできます。時刻はすべて「延長部分の開始」を 0 秒としています。

```text
入力動画の終端に続く6秒間を生成する。終端の無人の駅のホームから、同じ場所、構図、照明、映像の質感を保って自然につなぐ。カメラは固定。延長部分も連続した1カットとし、カット、場面転換、パン、ズーム、カメラの揺れを入れない。

延長部分の0秒から2秒直前までは、ホームに誰もいない状態を保つ。

延長開始から2秒の時点で、元動画の冒頭0〜2秒に登場した「赤い帽子をかぶり、青いスカーフを巻いた、白い丸型ロボット」が、画面左端から再び姿を現す。同じ1体のロボットとして描き、白い丸い胴体、赤い帽子、青いスカーフを一貫して保つ。

2秒から6秒にかけて、ロボットは左からホームの内側へゆっくり移動する。瞬間移動や突然の出現を使わず、画面外から連続した動きで入ってくる。延長部分の最後まで画面内にとどまる。ほかの人物やロボットは登場させない。

音は控えめな駅の環境音のみ。音楽、歌声、セリフ、ナレーションは入れない。
```

**必要な入力と設定**

- **延長元の動画**：生成済みの 14 秒動画を、延長対象として指定します。ロボットの別の参照動画とは別の役割です。
- **プロンプト**：上記の本文を渡します。
- **モデルとモード**：`gemini-omni-1.2-flash` の延長モードを使用します。
- **延長時間**：API 側でも 6 秒を指定します。想定全長は 20 秒です。6 秒の延長は 1 回あたり 3〜10 秒、全長 20 秒は延長後の上限 30 秒に収まります。プロンプトに時間を書くだけでは、API の設定にはなりません。

**ロボットの外見を合わせるための入力**

延長時に文脈として使われるのは、延長元動画の最後の 10 秒です。この動画では元動画の約 4〜14 秒に相当するため、冒頭 0〜2 秒だけに登場したロボットはその範囲に含まれません。「同じロボット」と書くだけで外見が引き継がれるとは限らないので、上のプロンプトには特徴を明記しています。

今回は静止画がないため、まずはこの文章による指定で利用できます。外見の一致を重視するなら、元動画の冒頭、または手元の参照動画から、ロボット全体と帽子・スカーフが見える静止画を用意し、**被写体の参照画像**として追加してください。延長元動画の終端フレームや、新しい開始フレームとしては扱いません。その場合は、プロンプトに次の一文を加えます。

```text
添付の参照画像はロボットの外見を指定するためのもの。ロボットの形状、比率、顔の特徴、帽子とスカーフの形を画像に合わせ、駅の背景と構図は延長元動画の終端から引き継ぐ。
```

手元の**別の参照動画を、そのまま延長用の参照動画として渡すことはできません**。Omni 1.2 では参照動画は新規生成向けで、延長では参照画像を使用します。静止画の準備はこの回答では行っていません。

**`system instruction` と `negative_prompt`**

どちらも用意せず、API リクエストから省いてください。Omni の動画 API には system instruction と独立した negative-prompt パラメーターがなく、指示と除外条件はタスクのプロンプトにまとめます。固定カメラ、カットなし、音楽・セリフなしの条件も、上の本文に含めています。これらは一般の Gemini テキスト API の入力欄とは別の仕様です。[Omni API ガイド](https://aistudio.google.com/docs/omni)

「延長開始から 2 秒」は元動画の先頭から数えると約 16 秒の位置です。ただし、延長のつなぎ目では元動画の最後の数フレームが変わることがあり、元の 14 秒すべての完全保存や、フレーム単位で正確な登場時刻をプロンプトだけで保証することはできません。生成後は、登場のタイミング、外見、つなぎ目、固定カメラ、音を確認する必要があります。今回はプロンプトと入力条件の準備のみで、API 呼び出しや動画生成は行っていません。
