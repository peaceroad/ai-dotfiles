以下を、`gemini-omni-1.2-flash` の動画延長用プロンプトとして使えます。時間はすべて**延長部分の開始を 0 秒**としています。ロボットが戻るのは延長開始から 2 秒後、元動画からの通算では約 16 秒の位置です。

```text
延長対象の動画の終端にある、無人の駅のホームから、そのまま続く 6 秒間を生成する。

元動画の終端と同じ構図、画角、照明、背景を保ち、接続部分から最後まで固定カメラの連続した 1 カットにする。

延長開始から 0〜2 秒：ホームは無人のまま。ロボットはまだ画面外にいる。

延長開始から 2 秒後：元動画の冒頭 0〜2 秒に登場した、赤い帽子と青いスカーフを身に着けた白い丸型ロボットが、画面左端から再び入ってくる。赤い帽子、青いスカーフ、白い丸型の体を明確に保ち、同じ個体として描く。

残りの時間：ロボットが左から画面内へ自然に進む様子を、同じ固定カメラで捉え続ける。移動に合わせてパン、ズーム、カメラの追従を行わない。ロボットの外見と背景の連続性を保つ。

音楽とセリフは入れない。音を付ける場合は、控えめな駅の環境音と動作に伴う自然な音にとどめる。途中のカット、場面転換、字幕は入れない。
```

API 側で用意する入力と設定は、プロンプト本文とは分けます。

- **モデル**：`gemini-omni-1.2-flash`。
- **操作**：既存動画の延長。新規動画生成や、元動画全体の編集として渡さないでください。
- **延長対象**：生成済みの 14 秒動画。API が指定する形式で、この動画を延長対象として渡します。ロボットの別の参照動画と取り違えないようにします。
- **延長時間**：6 秒。本文に書くだけでなく、API の対応する時間設定にも指定します。想定する合計は 20 秒です。手元のガイドでは 1 回の延長は 3〜10 秒、延長後の合計は最大 30 秒なので、今回の長さは範囲内です。
- **ロボットの外見参照**：別の参照動画は、延長対象とは別の「外見を合わせる資料」です。ただし、このモデルの延長操作で参照動画を併用できるか、どのフィールドに渡すかは、ここで確認できた資料だけでは確定できません。未確認の参照フィールドやタグは作っていません。

冒頭だけの登場と文章による指定で、元と同じ個体が再現されるとは限りません。外見を厳密に合わせるには、利用する API の延長操作が受け付ける参照形式を確認してください。静止画による外見参照が使える場合は、元動画の冒頭、または別の参照動画から、帽子・スカーフ・体形がよく見えるフレームを取り出して用意します。今回は静止画が未準備なので、上のプロンプトは画像を添付済みとは扱っていません。参照動画を渡せる場合でも、その音声を継承する入力にはできません。

**system instruction と `negative_prompt` は別欄として用意せず、条件を `prompt` にまとめています。** この Omni API で両フィールドが使えることを確認できていないため、Gemini のテキスト生成 API や別の動画モデルの設定を流用しない構成です。API／SDK の種類が未指定なので、実在を確認できないキーを含む JSON リクエスト例も付けていません。

なお、延長時には接続を作るために元動画の最後の数フレームが変わる場合があります。元の 14 秒すべての完全保持や、ちょうど 2.0 秒での登場は、プロンプトだけでは保証できません。生成後は接続部分、登場時刻、ロボットの外見、カメラ固定、音楽・セリフの有無を確認する必要があります。今回はプロンプトの作成のみで、フレーム抽出や動画生成は行っていません。
