# dot-toolkitを使い始める

`dot-toolkit`は、個別の作業条件や自作スキルの保存場所を、dotへ毎回説明する手間を減らすための、非公式・実験的なプラグインです。継続的に使うメインのdot向けに、個別指示の読み方と仕事に合うスキルの選び方を、共通スキル`dot-guidelines`へまとめています。

## まずChatGPT Webでインストールする

配布者からdot-toolkitのZIPまたは共有プラグインを受け取ります。ソースからZIPを作る場合は、[パッケージの用意](setup.md#パッケージを用意する)を参照してください。

1. ブラウザーでChatGPTを開き、dotを使うアカウントとワークスペースを選びます。
2. `dot-toolkit`をプラグインとしてインストールします。ZIPを受け取った場合は、利用できるプラグインアップロード機能で追加し、インストール状態まで確認します。チャットへのZIP添付やファイル保存だけでは完了しません。
3. メインのdot会話で、インストールした`dot-guidelines`を読めるか確認します。

画面上の操作と、アップロード機能がない場合の確認先は、[インストールと初期設定](setup.md#1-chatgpt-webでプラグインをインストールする)にあります。ローカルのCodexへのインストールや、リポジトリのソースが読めることを、dotで利用できる証拠にはしません。

## 必要な設定をdotに頼む

インストール確認後、個別指示やファイルで管理するスキルを用意したい場合は、メインのdotへ「dot-toolkitで初期設定して」と依頼します。0.2では手順も同梱されているため、別の`dot-setup.md`を添付する必要はありません。

個別指示と追加スキル候補は、それぞれ今渡す・後で渡す・今回は不要を選べます。候補を見てから、配置するスキルだけを承認します。共通候補をすべて使う必要はなく、空の個別ファイルを用意する必要もありません。

ここで行うスキルの配置は、dot自身のクラウドへスキル一式をコピーする作業です。最初の`dot-toolkit`のインストールや、ChatGPTへの別プラグイン・スキルの登録とは異なります。[初期設定で選ぶこと](setup.md#2-必要なクラウド設定を依頼する)で詳しく説明します。

## 普段は仕事をそのまま依頼する

インストールと必要な設定を確認したら、普段の仕事を依頼できます。たとえば`prompt-design`を配置した場合は、「この依頼文の曖昧なところを減らして」と頼みます。共通指示は、こうした依頼から関係するスキルを選び、必要な資料を読んで作業する方針を定めています。

利用前に新しい会話や環境を用意して試験する必要はありません。ただし、0.2の暗黙のスキル選択や継続性は、実際のメインdotでの受け入れ確認が未完了です。通常利用の開始確認と、動作を検証済みとするための試験は[分けて扱います](setup.md#読み込みと自動選択の受け入れ確認)。

## 利用上の前提

このプラグインは、dot本体の設定・権限・記憶を置き換えません。指示ファイルを置いても、利用者のPCや外部サービスへのアクセス権は増えません。個別指示や実際のスキル在庫は非公開として扱います。

製品自体の説明は、OpenAIの[dotの始め方](https://help.openai.com/en/articles/20001530-getting-started-with-your-dot)、[プライバシー・セキュリティ・安全性FAQ](https://help.openai.com/en/articles/20001529-dots-privacy-security-and-safety-faqs)を参照してください。このガイドのファイル配置と保守方法はdot-toolkit独自の運用です。
