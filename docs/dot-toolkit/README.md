# dot-toolkitを使い始める

`dot-toolkit`は、いつも守ってほしい指示や自作・開発中のスキルの場所を、dotへ毎回説明する手間を減らすための、非公式・実験的なプラグインです。共通スキル`dot-guidelines`が、継続的に使うメインのdotへ、個別指示の読み方と依頼にあうスキルの選び方を伝えます。

利用者固有の指示やタスク用スキルは同梱せず、必要なものだけをdotのクラウドへ追加します。ChatGPTで通常行うスキル・プラグインの導入は、引き続きそのまま使えます。

## インストールして、dotから使えるか確認する

配布者からZIPまたは共有プラグインを受け取り、dotを使うアカウントとワークスペースで、ChatGPT Webからインストールします。ZIPの場合はプラグインアップロード機能で追加してから、インストール済みになったことを確認します。チャットへZIPを添付するだけでは完了しません。

次に、メインのdotへ次のように依頼します。

> インストールしたdot-toolkitのdot-guidelinesを読めるか確認して。

ソースからのZIP作成、Webでの操作、利用できない場合の確認先は、[インストールと初期設定](setup.md#1-chatgpt-webでプラグインをインストールする)にあります。ローカルCodexでのインストールやリポジトリの読取りは、dot側で使えることの確認とは別です。

## 必要な場合だけ、クラウドの設定を頼む

個別指示やタスク用スキルをファイルで管理したい場合は、「dot-toolkitで初期設定して」と頼みます。0.2では手順も同梱しているため、別の`dot-setup.md`は不要です。

個別指示と追加スキル候補は、それぞれ今渡す・後で渡す・今回は不要を選べます。候補の用途や変更内容を見て、使うスキルだけを承認します。すべての候補を採用したり、空の個別ファイルを作ったりする必要はありません。

ここでは、承認したスキルのフォルダー一式をdotのクラウドへ配置します。最初のプラグイン導入とは別の作業で、ChatGPT側の既存スキルを自動でコピー・更新するものではありません。選択と配置の流れは、[必要なクラウド設定を依頼する](setup.md#2-必要なクラウド設定を依頼する)を参照してください。

0.1を利用中の場合は、新規設定として既存ファイルを置き換えず、[0.1から0.2への移行](setup.md#01から02へ移行する)を依頼してください。

## 普段の仕事を依頼する

共通スキルを読めることと、今回必要な設定を確認できたら、普段の仕事を依頼できます。たとえば`prompt-design`を配置した場合は、「この依頼文の曖昧なところを減らして」と頼みます。スキル名や保存場所を毎回指定する必要はありません。

確認済みの利用環境や版に変更の兆候がなければ、インストール確認や初期設定を繰り返しません。個別指示や追加スキルが不要なら、その設定を待たずに利用できます。

0.2での暗黙のスキル選択と継続性は、実際のメインdotでの受け入れ確認が未完了です。通常利用を始めるための確認と、動作を検証済みとするための試験は[分けて扱います](setup.md#読み込みと自動選択の受け入れ確認)。

このプラグインはdot本体の設定・権限・記憶を置き換えず、利用者のPCや外部サービスへのアクセス権も増やしません。個別指示や実際のスキル在庫は非公開として扱います。

製品自体の説明は、OpenAIの[dotの始め方](https://help.openai.com/en/articles/20001530-getting-started-with-your-dot)と[プライバシー・セキュリティ・安全性FAQ](https://help.openai.com/en/articles/20001529-dots-privacy-security-and-safety-faqs)を参照してください。このガイドのファイル配置と保守方法はdot-toolkit独自の運用です。
