# Gemini 4向け指示設計スキルの再構築

2026年11月15日、`prompt-gemini-reference`を`gemini-instruction-design`へ置き換えた。対象はリポジトリの配布ソースであり、インストール済みコピー、Apps上のSkills、アカウント設定は変更していない。[計画](../plans/gemini-4-skills-update-plan.md)に沿った全面改稿で、プラグイン版は`0.4.0`とした。

この文書は最終的な構成と確認範囲を説明する。入口の比較は[使いやすさ評価](gemini-usability-review.md)、モデル・Skills仕様との整合は[公式指針の照合記録](gemini-4-prompt-audit.md)を参照。評価に使った版と現行ソースは、検証の節で区別する。

## 責務と構成

`prompt-design`と`agent-workflow-design`の本文・参照は変更していない。Gemini側から共通の指示設計方法を利用し、実行制御を設計する場合だけワークフロー側を併用する。Antigravityを対象にすること自体は、ワークフロー設計を必須にする理由にしていない。

入口からApps、Gemini CLI、Antigravity、API、媒体入力、画像、動画の7参照を条件付きで読む。単発の文章プロンプトは共通手法と入口で扱い、画像プロンプトを書くApps Skillなどの複合依頼では必要な参照を組み合わせる。生成するApps Skillへ、設計側の共通スキル依存を転写しない。Gems／Opalの専用移行ガイドは配布対象に含めない。

汎用モデルはCarbon・Argon・Hydrogenを基準とし、Gemini 3系の互換説明を削除した。画像モデルのIDに`gemini-3`が含まれることとは区別する。Nano Banana 2.1とOmni 1.2を中心に、明示された画像モデルやCloud側Veoの提供面を保持する。

## 設計判断と旧指示の扱い

改修前の基点は`b248ee5dbcd1aef944f3872b64896ff440de987c`。意味を残す場所は次のとおり。

- 一般的な意図保持、指示の強さ、根拠、適切な制御層、報告は既存の`prompt-design`を利用する。Gemini側は対象・参照選択・提供面ごとの条件・実行との境界を担当する。入力と問いの配置を一律には指定しない。
- 再利用する指示と資料の分担は、Apps Skillsの本文と参照として設計する。旧製品の移行期限やUI操作は、現行Skillsの設計指針へ持ち込まない。
- メディア入力の出典・ページ・時刻、観測と推論、欠けた入力の扱いは媒体入力参照に残した。
- 生成時の参照役割、確定コピー、許された変更、画像の反復、動画の時間・接続・音声は、それぞれ画像と動画へ分けた。
- Gemini 3のsampling助言、旧モデルの回避策、全用途で読む共通層は廃止した。API設定・状態保持はAPI参照が所有する。

旧名の同用途入口は残していない。既存の明示呼出しは新名へ更新する必要がある。過去のレビューの旧ソースリンクは基点コミットへ固定し、既存の評価manifestや観測記録は変更していない。

## 検証の範囲

以下の2件の指示生成試行は、初回の8参照版を対象とした証拠である。現行の7参照版や、後の仕様補正をそのまま実測した結果ではない。各比較の対象版・入力・応答は、それぞれの評価記録に保持する。

代表依頼と判定条件は[合成ケース](../../evals/agent-design-tools/prompt-design/gemini-4-rewrite/cases.json)へ保存した。これは回帰定義であり、すべてを実行済みという意味ではない。自動選択、指示生成、生成された指示のGemini上での動作は別々に評価する。

構造検証では`quick_validate.py`と`npm run check:plugins`が成功した。後者は26件成功し、隔離したプラグイン内のリンクと、`prompt-design`＋新スキルを単独配置したときの参照到達性も確認している。共通2スキルの差分がないこと、LF、差分の空白、文書リンクも確認した。

[独立試行の抜粋と判定](../../evals/agent-design-tools/prompt-design/gemini-4-rewrite/observations.md)には、Apps向け画像プロンプト作成スキルとAntigravity向けバグ修正指示の2件を残した。どちらも要求された指示本文を生成でき、前者はAppsと画像の参照を組み合わせ、後者は独自の継続ループを追加しなかった。参照一覧は実行担当の自己報告であり、完全なツールログの計測ではない。

この試行はCodexで候補を明示指定して行った指示生成である。旧版との同条件の行動比較、カタログからの自動選択、Gemini実機での取込み・自動発火・生成品質・速度・費用は今回の証拠には含めない。残る8件は回帰定義で、実行済みではない。構造と限定した成果物の確認に基づきソース版を採用し、実機の性能向上は主張しない。

## 公式資料の確認と残る検証

改稿に必要なCarbon・Argonのdeveloper guide、Hydrogenのモデル・API資料、Apps・Gemini CLI・AntigravityのSkills仕様、Nano Banana・Omniの関連資料は本文を確認済み。採用した条件と出典は[公式指針の照合記録](gemini-4-prompt-audit.md)と各参照にまとめている。

Apps管理ヘルプでは、ファイルの個別更新と全体再アップロードの説明が併存するため、実操作時に対象UIで確認する。Gemini実機での取込み、自動選択、参照利用、タスク実行は未検証。クライアントのモデル提供状況や実際の読み込みも、ソース検証だけでは判断しない。
