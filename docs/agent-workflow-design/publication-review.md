# agent-workflow-design 評価記録の公開前確認

2026年9月6日。評価記録の機微情報と保存内容を確認し、参照パスを公開用に加工した。新しい動作評価は行っていない。

## 公開用の加工

応答ファイルの入力出典欄に残っていた、ユーザー名を含むローカル絶対パスの先頭を置き換えた。

- チェックアウト内の参照は、リポジトリルートからの相対パスにした。
- 一時評価ディレクトリ内の参照は、`<evaluation-workspace>/<version>/...`にした。版とソース内の位置は保持している。

`<evaluation-workspace>`は試行時の作業場所を表す論理名で、公開リポジトリの実在ディレクトリではない。

加工対象の応答は公開用の版であり、元のバイト列とは異なる。変更は参照パスの先頭だけで、生成された設計、評価入力、判定条件、モデル設定、評価対象版、スナップショット、採否判断は保持している。

## 確認範囲と結果

このスキルの評価記録と、評価に使用した既知の一時ディレクトリを対象に、認証情報、連絡先、ローカルパスなどをパターン検査と文脈確認で調べた。JSON内の文字列も展開して検査し、評価入力が架空の業務設定であることを確認した。

公開加工後の評価記録と関連ドキュメントを再検査し、追加の機微情報は検出しなかった。この確認はリポジトリ全体や端末全体の監査ではなく、あらゆる機微情報の不在を保証するものではない。

## 加工前後の照合

[publication-manifest.json](../../evals/agent-design-tools/agent-workflow-design/publication-manifest.json)に、変更したファイル、加工前後のサイズとSHA-256、置換箇所を記録した。元の個人情報を含むパスは記録へ複製していない。

過去のmanifestは変更していない。加工対象では、過去のハッシュを`files[].original`と対応させ、現在の公開ファイルを`files[].published`で照合する。加工対象外の記録は、過去のmanifestで直接照合できる。

これらのハッシュと参照関係を確認した。加工済み応答は、検証時のメモリ内で参照パスだけを元に戻すと元のサイズ・SHA-256に一致し、ほかの箇所が変わっていないことも確認した。

## 保存場所

既知の一時ファイルをGit履歴、保存済みスナップショット、応答記録と照合し、プロジェクト側に不足する評価資料は見つからなかった。一時コピーは公開リポジトリには含まれない。

今後も、評価入力・応答・保存版・manifestは`evals/agent-design-tools/agent-workflow-design/`に、説明や採否判断は`docs/agent-workflow-design/`に保存する。一時出力から残す必要のある証拠は、公開前に検査してこれらの場所へ保存する。
